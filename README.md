# Motion-Anchor-FFXI
Ashita v4 Addon for FFXI to help relieve motion sickness while on a chocobo.

V 1.0
The addon draws a static grid on the screen when you are on a chocobo.
The grid is removed once you dismount.

Instructions: 
Download raw file MotionAnchorFFXI.lua
Place it in a folder named MotionAnchorFFXI
Move the folder to your ashita/addons directory
load the addon

There are no configurable settings in this version.
There are no known conflicts with other addons.

Future development is intended to include 25 points of selectable static marks on the screen, following each intersection of the grid.
These marks will be customizable in width, length, color, and transparency.
The grid lines will be configurable in width, color, and transparency.
A GUI to configure those settings is intended to be added in the future and a checkbox to flip between always on and only on while riding a Chocobo is intended.
